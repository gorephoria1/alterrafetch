this is a beta version of alterrafetch so be ready for bugs errors etc
to install alterrafetch git clone it first
1 git clone it 
```bash
git clone https://github.com/gorephoria1/alterrafetch
```
2 type make to make it
```bash
make
```
if you dont have make installed install it thru your package manager
```bash
debian/ubuntu/mint/kali sudo apt install make
fedora sudo dnf install make
arch/manjaro/endeavor/cachyos sudo pacman -S make
```
3 install it
```bash
sudo make install
